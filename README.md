# homebrew-tap

Personal Homebrew tap. Formulae for CLI tools live here; more can be added over time.

```bash
brew tap yutat23/tap
```

## Formulae

| Formula | Description |
| --- | --- |
| [lsoff](https://github.com/yutat23/lsoff) | CLI/TUI for listing listening TCP/UDP ports |

```bash
brew install lsoff
```
